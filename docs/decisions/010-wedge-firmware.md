# ADR 010: Wedge-eye firmware (dino_wedge_c3)

Status: code complete 2026-11-12 (firmware name "Dino Wedge", version 0.4.0-wedge); NOT yet run on the board.

## Why
The owner picked page D (Wedge) of the "new eyes" sheet: flat-cut wedge eyes and a small mouth, no pupil, brow or nose.
The ask: the same firmware logic as today, only a new name.

## Decisions
- **One extra PlatformIO env, same sources.** `dino_wedge_c3` extends `dino_c3` and adds `-DDINO_WEDGE=1`,
  `FIRMWARE_NAME "Dino Wedge"`, `FIRMWARE_VERSION "0.4.0-wedge"`. The brain, modules, input, life, sounds, power, soak,
  Wi-Fi, boot film and scene tables are not touched. `dino_c3` stays byte-for-byte the old face (`face_check.py` passes).
- **Only the face drawing is swapped**, inside `face/face.cpp` behind `#ifdef DINO_WEDGE`: `eye()`, `mouth()` and the 24
  presets live in `face/face_wedge.inc`. The API (`EyeO`, `FaceO`, `Ex`, `Mouth`, `resolve`) is unchanged, so every clip
  and every caller compiles as before. Added: `FaceO::my()` setter and optional scale arguments on `EyeP::apply`.
- **Old scene overrides are scaled.** Scenes set eye w/h for the 28 x 30 slab; in the wedge build those overrides are
  multiplied by 18/28 and 14/30. Presets are written in wedge units and are not scaled.
- **Brows have no drawing.** A raised brow makes the eye taller (+0.8 px per lift unit); a hard brow (a >= 2) slants the lid.
  Pupils are gone: heart, star and spiral become whole-eye shapes. Nostrils are off (`nose = 0`).
- **8 presets are our own wedge versions** (unimpressed, focus, hungry, chew, scared, determined, squeeze, yawn): page D
  only has 16 moods. Assumption, for the owner to review on the sheet.
- **The sheet is the reference.** `art/reference/dino-wedge-v1/` (`wedge_face.js` is hand-authored, `rig_wedge.js` and
  `Dino Wedge Sheet.html` are generated by `tools/build_wedge_sheet.js`). `tools/face_check_wedge.py` compares the C++
  wedge rig with that rig frame by frame, in double and float.
- **Faces are drawn 25 % bigger than page D** (`FACE_K` 1.25 in `face.cpp` and `wedge_face.js`, owner request 2026-11-12): eyes, spacing, mouth and effects scale together. The default build uses 1.
- **Boot film: same film C, wedge eyes on Dino's face (owner request 2026-11-12).** Timings, steps, zooms and layout are unchanged. In the wedge build only the art of Dino's face differs: the sprite's face window (`FACE_WEDGE`, kept apart from `FACE` because `tools/gen_*_art.py` read it) and the two "face grows" steps (`drawWedgeEye`, `drawWedgeMouth`), so the zoom lands on the wedge live face. The default build and the brand art are unchanged. Preview: `pio run -e play_boot_wedge -t upload`.
- The spiral eye uses 38 points (the firmware polyline holds 40), in both the sheet and the firmware.

## Checked (2026-11-12)
Fact: `face_check_wedge.py` 251/251 frames match (double and float); `face_check.py` still 251/251 on the old face;
`pio run -e dino_wedge_c3`, `dino_c3` and `play_dino_wedge` build; `pio test -e native` 132 pass. Wedge build is 1,066,266 B
flash (81.3 %), 70,636 B RAM, no warnings. Games and Friends clips are not in the firmware yet, so only R, L, U are checked.

## Not checked
How the face looks on the real 0.96" panel, and whether the 1 px mouth reads at arm's length. Flash by hand:
`pio run -e dino_wedge_c3 -t upload && pio device monitor -e dino_wedge_c3`, or `play_dino_wedge` for every clip.
