## Wi-Fi setup ("connect your dino", ADR 005)
Code complete 2026-11-07, not yet run on the board. Menu > Wi-Fi opens dino's own WPA2 network `DINO-xxxx` (10-character password on the OLED); a phone joins, the setup page opens by itself, picks the home Wi-Fi; saved to flash after it connects. 30 new native tests (`test_wifi_setup`, wifi cases in `test_utility_machine`; 95 in total), all envs build, flash 75.6% (was 69.6%). The page's JavaScript was run in a browser against a mock of the four routes (success, wrong password, rejected input, hostile network name); the real web server on the chip is unverified. Board checks: `docs/wifi-setup-checklist.md`. Setup page restyled 2026-11-08 in the Pixling brand language (logo + Dino art generated by `tools/gen_portal_art.py`, ADR 005); the OLED screens were already in the sheet's style.

## Boot-up animation (ADR 006, 2026-11-07)
Owner chose film **C zoom** after previewing three candidates on the board (`env:play_boot`; A born 4.4 s, B dino 3.9 s, C zoom 4.9 s). Now in the main firmware: plays on every boot, a tap skips to the live face (the tap is swallowed, so it does not pet the dino), key `B` replays, `FEATURE_BOOT_INTRO` / `BOOT_INTRO_FILM` in `config.h`. Frames are data in `firmware/src/boot/`; the last frames are drawn by the real face rig. 111 native tests pass (16 new), all envs build, flash 76.2%. **Not yet run inside the main firmware on the board**: `docs/boot-film-checklist.md`. Alarm-after-film is safe because the clock is unsynced right after power-on (assumption for resets: see ADR 006).

## Known risks

- Face rig render cost on the C3 is unmeasured (measured later: 8-216 ms/frame, see D3). Fallback: pre-bake 416 frames (~416 KB).

## Known gaps after D4 (see also docs/debug-play-dino.md)
- Pet = short Tap (the sheet says hold 0.6 s: no such touch event yet). Firm double tap -> RAWR not wired (DoubleTap shows the time).
- Tilt "level" event missing: a held tilt can replay the tilt clip every 4 s.
- Shake threshold is the firmware default (1.7 g, 3 peaks / 1 s); the sheet says 1.2 g, 3 jerks / 600 ms. Tune `GESTURE_SHAKE_*` on the board.
- Voice timing is counted from when the home clip is built, not from what the OLED shows.
- A frame render (up to ~100-200 ms for glasses frames) runs inside the loop and can delay the alarm tick by that much.
- Menu has 5 slots (Clock, Alarm, Focus, Stopwatch, Back); Games/Friends/Messages/Settings come later. Stopwatch icon is drawn in code (not in the sheet).
